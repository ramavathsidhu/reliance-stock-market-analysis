Reliance Industries Stock Market Analysis

1. Project Overview

This project analyzes the historical stock market data of Reliance Industries using Python. The main purpose is to understand stock price movements, returns, and market volatility.

2. Objective

- Analyze historical stock prices.
- Calculate daily stock returns.
- Understand stock price trends.
- Calculate daily and annual volatility.
- Identify the best and worst trading days.
- Analyze moving averages.

3. Tools & Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- yfinance

4. Data Analysis

The project uses historical Reliance Industries stock data (RELIANCE.NS).

Analysis performed:

- Data collection and cleaning
- Descriptive statistics
- Daily return calculation
- Moving average calculation (50-day and 200-day)
- Daily and annual volatility
- Best and worst daily returns
- Total return and CAGR calculation

5. Visualizations

- Reliance Industries Closing Price
- 50-Day and 200-Day Moving Averages
- Daily Returns Visualization

6. Key Findings

- Starting Stock Price: ₹672.22
- Ending Stock Price: ₹1,164.90
- Total Return: 73.29%
- CAGR: 8.39%
- Daily Volatility: 1.74%
- Annual Volatility: 27.67%
- Best Daily Return: 14.72%
- Worst Daily Return: -13.15%

7. Conclusion

This project helped me understand historical stock market trends, daily returns, moving averages, and volatility using Python.

It demonstrates how Python libraries can be used for financial data analysis and visualization.
